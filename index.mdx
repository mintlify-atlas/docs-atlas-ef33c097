Gemma is a JAX-based Python library for using and fine-tuning the Gemma family of open-weight large language models from Google DeepMind. With a unified API that spans Gemma 2, 3, 3n, and 4, you can run text, image, and audio inference — and fine-tune models using LoRA — with just a few lines of code.

## Get started in three steps

<Steps>
  <Step title="Install JAX and Gemma">
    First install JAX for your hardware (CPU, GPU, or TPU), then install the `gemma` package from PyPI.

    ```bash
    pip install jax  # or jax[cuda12] for GPU
    pip install gemma
    ```
  </Step>
  <Step title="Download a checkpoint">
    Gemma model weights are hosted on Kaggle Hub. Download the Flax variant for use with this library.

    ```python
    import kagglehub
    kagglehub.login()
    weights_dir = kagglehub.model_download('google/gemma-3/flax/gemma3-4b-it')
    ```
  </Step>
  <Step title="Run inference">
    Load the model and start a conversation using `ChatSampler`, which works with all Gemma versions.

    ```python
    from gemma import gm

    model = gm.nn.Gemma3_4B()
    params = gm.ckpts.load_params(gm.ckpts.CheckpointPath.GEMMA3_4B_IT)

    sampler = gm.text.ChatSampler(model=model, params=params)
    response = sampler.chat("Explain transformers in one paragraph.")
    print(response)
    ```
  </Step>
</Steps>

## Supported models

Gemma supports the full model family across four generations:

| Family | Sizes | Multi-modal |
|--------|-------|-------------|
| Gemma 2 | 2B, 9B, 27B | Text only |
| Gemma 3 | 270M, 1B, 4B, 12B, 27B | Text + images |
| Gemma 3n | E2B, E4B | Text only (JAX) |
| Gemma 4 | E2B, E4B, 26B-A4B, 31B | Text + images + audio |

<Note>
  All models are available in both pre-trained (PT) and instruction-tuned (IT) variants. For most use cases, use the IT variant.
</Note>
